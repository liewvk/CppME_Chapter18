# C++ Programming Made Easy - Chapter 18

This repository contains a set of small C++ example programs that match the concepts introduced in Chapter 18 of the book "C++ Programming Made Easy". The examples focus on fundamental object-oriented programming concepts such as classes, objects, constructors, destructors, and member functions.

## Repository overview

The project is organized as a Visual Studio C++ solution with multiple standalone example folders. Each folder contains a small C++ program plus its Visual Studio project files (.vcxproj and .vcxproj.filters).

### Main project files

- `CppME_Chapter18.cpp` - default template file generated by Visual Studio, containing a basic "Hello World" console application.
- `CppME_Chapter18.slnx` - solution file for the project.
- `CppME_Chapter18.vcxproj` - main project configuration.
- `CppME_Chapter18.vcxproj.filters` - project filter layout for Visual Studio.

## Example programs included

The repository includes multiple example programs demonstrating different class features:

### Example 18.4 - Default constructor and object display
- Folder: `CppME_CHapter18_Example18.4`
- Focus: creating a `Student` class with a default constructor and a display function.
- Demonstrates: default member initialization and simple object behavior.

### Example 18.7 - Rectangle class with default values
- Folder: `CppME_Chapter18_Example18.7`
- Focus: `Rectangle` class with default length and width values.
- Demonstrates: method usage, default state, and an `area()` calculation.

### Example 18.8 - Parameterized constructor
- Folder: `CppME_Chapter18_Example18.8`
- Focus: `Student` object creation by passing values to a constructor.
- Demonstrates: parameterized constructors and initializing object state with input arguments.

### Example 18.10 - Book class with constructor and display
- Folder: `CppME_Chapter18_Example18.10`
- Focus: `Book` class storing title, author, and price.
- Demonstrates: object attributes and output formatting.

### Example 18.11 - Multiple objects using default and parameterized constructors
- Folder: `CppME_Chapter18_Example18.11`
- Focus: `Student` class with both default and overloaded constructors.
- Demonstrates: construction of multiple objects and printing their data.

### Example 18.12 - Constructor validation
- Folder: `CppME_Chapter18_Example18.12`
- Focus: `Student` class with a constructor that validates marks within the range 0 to 100.
- Demonstrates: input validation inside constructors.

### Example 18.13 - Employee data model
- Folder: `CppME_Chapter18_Example18.13`
- Focus: `Employee` class with name and salary attributes.
- Demonstrates: encapsulation and data display through a method.

### Example 18.26 - Default and custom constructors together
- Folder: `CppME_Chapter18_Example18.26`
- Focus: a `Student` class that uses both a default constructor and a constructor with arguments.
- Demonstrates: constructor overloading and object initialization alternatives.

### Example 18.27 - Destructor demonstration
- Folder: `CppME_Chapter18_Example18.27`
- Focus: `Message` class with a constructor and destructor.
- Demonstrates: object lifecycle messages and the role of destructors.

### Example 25 - Car class example
- Folder: `CppME_Chapter18_Example25`
- Focus: `Car` class with brand, color, and speed.
- Demonstrates: a simple real-world class design and method invocation.

## Chapter 18 learning themes

This repository is built around the core concepts typically taught in Chapter 18 of beginner C++ material:

- classes and objects
- member variables and member functions
- constructors
- constructor overloading
- default constructors
- destructors
- initialization of object data
- basic encapsulation and data display

## How to run the examples

This repository is set up as a Visual Studio C++ project, so the easiest way to run the code is:

1. Open `CppME_Chapter18.slnx` in Visual Studio.
2. If needed, select the example project or the root project.
3. Build the solution.
4. Run the program to see the example output in the console.

You can also open individual example folders and build each one as its own project if desired.

## Notes

- The project uses Microsoft Visual Studio project files, so it is primarily intended for Windows-based development.
- The examples are small and beginner-friendly, making them suitable for learning OOP concepts step by step.
- The repository is structured as a teaching resource rather than a large production application.
